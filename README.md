# 🌸 About Smart Learning

**Smart Learning** is a simple and modern learning management frontend designed to provide a smooth learning experience for:

🎓 **Students**

👩🏻‍🏫 **Mentors**

👑 **Administrators**

The application follows a soft **lavender, pastel purple, pink, and cozy study-inspired design**.

The goal is to keep the application easy to understand while still demonstrating a complete learning workflow.

📡 API Integration

The frontend communicates with the Django backend using Axios.

Axios Configuration
import axios from "axios";

const api = axios.create({
  baseURL: "http://127.0.0.1:8000/api/",
});

export default api;
Example API Request
const response = await api.get("courses/");

This allows React to receive course data from the Django REST API.

🚀 Getting Started
1. Clone the repository
git clone https://github.com/Neahans/smart-learning-frontend.git
2. Open the project
cd smart-learning-frontend
3. Install dependencies
npm install
4. Start the React application
npm start

The application will be available at:

http://localhost:3000
